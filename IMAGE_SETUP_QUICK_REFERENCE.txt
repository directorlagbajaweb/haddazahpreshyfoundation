❌ Images Don't Show
✓ Check filename matches exactly (case-sensitive on Mac/Linux)
✓ Verify file is in assets/images/ folder
✓ Refresh browser cache (Ctrl+F5)
✓ Ensure file format is .jpg or .png

❌ Text Hard to Read
✓ Choose a darker image
✓ Increase overlay opacity (85% → 95%)
✓ Use image with better contrast

❌ Image Distorted
✓ Use 1920×600px dimensions
✓ Use 16:9 aspect ratio
✓ Avoid extreme aspect ratios

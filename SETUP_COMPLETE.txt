🔧 CUSTOMIZATION OPTIONS (OPTIONAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ADJUST OVERLAY DARKNESS:

Current (85% - Good for most images):
from-rose-500/85 to-pink-600/85

Lighter (70% - Shows more image detail):
from-rose-500/70 to-pink-600/70

Darker (95% - Maximum text contrast):
from-rose-500/95 to-pink-600/95

HOW TO CHANGE:
1. Open HTML file (index.html, about.html, etc.)
2. Find the line with "from-rose-500/85 to-pink-600/85"
3. Change the number (85 to 70, 95, etc.)
4. Save and refresh browser

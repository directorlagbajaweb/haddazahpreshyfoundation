❓ COMMON QUESTIONS
───────────────────────────────────────────────────────────────────────────────

Q: Will my site still look good without images?
A: Yes! The rose/pink gradient shows while images load.

Q: How long do images take to load?
A: 1-2 seconds with optimized 400KB images on good internet.

Q: What if I want to change the overlay color?
A: Edit the CSS in HTML files - see HTML_CODE_REFERENCE.md

Q: Can I use my own images?
A: Yes! Any JPG or PNG works (optimize to 1920×600px).

Q: Will it work on mobile?
A: Yes! Images are responsive for all devices.

Q: How do I make text more readable?
A: Increase overlay opacity (85% to 95%) or choose darker image.

Q: Can I use different images for different sections?
A: Each section has its own image file, so yes!

Q: What file format should images be?
A: JPG or PNG both work great.

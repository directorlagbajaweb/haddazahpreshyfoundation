🚀 Quick Start Guide

Get your Haddazah Preshy website up and running in minutes

Step 1: Open the Website Locally

Test the website on your computer before deploying:

Double-click index.html to open in your browser

Your homepage will open immediately. Click navigation links to explore all pages.

Step 2: Customize Content

Update organization details in these files:

  • ✓ donate.html - Update bank account details
  • ✓ index.html - Update homepage tagline
  • ✓ All .html files - Update footer contact info
  • ✓ about.html - Update organization story

Open files with any text editor (VS Code, Notepad, etc.)

Step 3: Add Your Images

Place images in the images folder:

assets/images/your-image.jpg

Then reference in HTML:

<img src="assets/images/your-image.jpg" alt="Description">

Use authentic, empowering images of women

Step 4: Deploy to the Web

Choose one of these free options:

Option A: Netlify (Recommended)

  1. Go to netlify.com
  2. Sign up or log in
  3. Drag and drop your project folder
  4. Done! Site is live in seconds

Option B: GitHub Pages

  1. Push code to GitHub repository
  2. Go to Settings → Pages
  3. Select main branch and save
  4. Site available at github.com/yourusername/repo

Step 5: Set Up Custom Domain (Optional)

After deploying:

  1. Buy domain from GoDaddy, Namecheap, etc.
  2. Point DNS to your hosting (Netlify/GitHub)
  3. Connect in hosting dashboard settings
  4. Your site is accessible at your custom domain

⚠️ Important Checklist Before Launch

  • Update all contact information
  • Verify bank account details in donate.html
  • Add organization images
  • Update Privacy Policy with your practices
  • Update Terms of Service as needed
  • Test on mobile devices
  • Get legal review if required
